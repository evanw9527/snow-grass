## 1. 需求概述

在 snow-grass Activity 独立领域增加非破坏性语义去重和聚合统计接口，并在 Sedum 活动记录页展示去重后事件、总量、字符量、应用分布与每日趋势。

## 2. 范围

**In scope（本次做）**：

- 保留 `client_event_id` 上传幂等去重。
- 查询时按相同 Bundle ID、Unicode/空白规范化后的相同文本、5 秒窗口语义去重，不删除原始记录。
- Activity 分页支持去重开关并返回原始总数、去重数。
- 新增聚合接口，返回事件、字符、应用及每日趋势。
- Sedum 默认展示去重结果、汇总卡片、趋势和应用排行，并允许切换原始记录。

**Out of scope（本次不做）**：

- 不用启发式规则删除疑似输入法拼音，因为可能误删合法英文。
- 不物理清理既有重复数据，不把 Activity 数据写入 Chat、Memory、Agent 或 Skill。
- 不增加账号、多租户、窗口标题或跨设备同步。

## 3. 功能要点

## 5. API 接口清单

### Activity 去重分页

- **路径**：`/api/v1/activity-events/page`
- **方法**：`GET`
- **用途**：按相同筛选条件返回原始或语义去重后的记录。
- **关键请求参数**：`query`、`bundle_id`、`start`、`end`；`deduplicate`（bool，默认 false）；`dedupe_window_seconds`（1-300，默认 5）。
- **关键响应字段**：`items`、`total`、`raw_total`、`duplicate_total`、`page`、`page_size`。
- **数据来源**：本地 Activity 领域扩展。

### Activity 汇总

- **路径**：`/api/v1/activity-events/summary`
- **方法**：`GET`
- **用途**：按筛选条件返回聚合指标。
- **关键请求参数**：与分页筛选一致；`dedupe_window_seconds`（1-300，默认 5）；`timezone_offset_minutes`（-720 至 840，默认 480）。
- **关键响应字段**：`raw_event_count`、`unique_event_count`、`duplicate_event_count`、`character_count`、`active_app_count`、`daily`、`apps`、`generated_at`。
- **数据来源**：本地 Activity 领域扩展。

## 8. 技术实施方案

### 8.1 架构决策

| 决策 | 选择 | 原因 | 放弃的方案 |
|------|------|------|-----------|
| 去重位置 | Activity Service 查询时去重 | 原始记录可审计、规则可调整、领域解耦 | 入库时删除会造成不可恢复的数据损失 |
| 去重键 | Bundle ID + NFKC/空白规范化文本 + 5 秒窗口 | 过滤重试/重复回调，同时保留跨应用或相隔较久的合法重复输入 | 忽略大小写或删除拉丁文本会误伤英文 |
| 聚合位置 | snow-grass 后端 | 统计口径单一，Sedum 不需下载全部明文 | 前端聚合会增加隐私暴露和传输量 |
| 时区 | API offset 参数，默认 UTC+8 | 支持上海自然日且保留可测试性 | 固定数据库时区不利于迁移 |

### 8.2 数据流

```text
activity_events → ActivityRepository.list_filtered → ActivityService._deduplicate
→ ActivityService.summary/page → activity router → snowGrassApi
→ ActivityEventsPage → 统计卡 / 趋势 / 排行 / 去重列表
```

### 8.3 改动详情

- `schemas.py`：新增 `ActivityDailySummary`、`ActivityAppSummary`、`ActivitySummaryResponse`，分页增加原始与重复总数。
- `repository.py`：抽取过滤条件并新增稳定排序的 `list_filtered`。
- `service.py`：新增纯函数式规范化/去重，分页与汇总复用相同结果；字符数按 Unicode 字符计数。
- `router.py`：静态 `/summary` 放在动态 `/{event_id}` 前，校验窗口与时区参数。
- `tests/test_activity.py`：验证 5 秒内相同文本去重、不同英文/大小写/跨应用不误删、时间过滤和趋势日期。
- `snowGrassApi.js`：统一构造 Activity 查询参数，列表和汇总共用。
- `ActivityEventsPage.jsx`：使用同一筛选加载列表与汇总；增加模式切换和可访问空/错态。
- `activity.css`：保持钴蓝、白底、细边框，补充桌面/移动布局。

### 8.4 状态管理

沿用 React 本地 state；增加 `summary` 与 `deduplicate`，不引入全局状态库。

### 8.5 异常处理

| 场景 | 处理方式 | 涉及文件 |
|------|---------|---------|
| 汇总接口失败 | 保留最近列表并显示统一错误，可重试 | ActivityEventsPage.jsx |
| 空数据 | 统计显示 0，趋势/排行显示空态 | ActivityEventsPage.jsx |
| 非法时间/窗口 | snow-grass 返回 422 | router.py、service.py |

## 9. 验收标准（AC）

### AC1：非破坏性语义去重

- **Given**：同一应用 5 秒内存在两条规范化后相同的记录，以及不同英文记录。
- **When**：请求去重分页或汇总。
- **Then**：相同记录计为 1 条，英文记录分别保留，数据库原始条数不变。

### AC2：统计汇总

- **Given**：多个应用、多个自然日的 Activity 数据。
- **When**：请求 `/summary` 并携带筛选与时区。
- **Then**：返回原始/唯一/重复数、字符数、应用数、按日趋势与应用排行，合计一致。

### AC3：Sedum 统计展示

- **Given**：snow-grass 返回汇总和去重分页数据。
- **When**：进入活动记录页或改变筛选。
- **Then**：统计卡、趋势、排行和列表同步更新，默认显示去重记录且可切换原始记录。
