## 1. 需求概述

在 Sedum Agent 输入框增加当前会话最近一次实际组装上下文的 Token 占用，展示百分比及已用/预算。

## 2. 范围

**In scope（本次做）**：
- 实时请求从 `run.started.context_stats` 更新占用。
- 打开历史会话时从 Memory API 恢复 `last_context_stats`。
- 输入框底部展示环形刻度、已用/预算与悬浮完整说明。
- 无统计时明确展示暂无数据。

**Out of scope（本次不做）**：
- 不把累计模型 Token 用量当作上下文占用。
- 不估算尚未发送的输入内容。
- 不修改 Snow Grass 上下文裁剪预算。

## 3. 功能要点

| # | 功能点 | 描述 | 优先级 |
|---|--------|------|--------|
| 1 | 实时占用 | 每次 run.started 使用真实 context_stats 更新 | P0 |
| 2 | 历史恢复 | 切换会话读取 last_context_stats | P0 |
| 3 | 上下文刻度 | 输入框底部展示百分比、已用和预算 | P1 |

## 5. API 接口清单

### 会话 Memory
- **路径**：`/api/v1/sessions/{session_id}/memory`
- **方法**：`GET`
- **用途**：恢复历史会话最近一次上下文统计。
- **关键请求参数**：`session_id`（路径参数，必填）。
- **关键响应字段**：`last_context_stats.token_budget`、`estimated_tokens`、各来源 token。
- **数据来源**：当前 Snow Grass API。

### 会话消息流
- **路径**：`/api/v1/sessions/{session_id}/messages/stream`
- **方法**：`POST/SSE`
- **用途**：从 `run.started.context_stats` 获取本次真实占用。
- **关键请求参数**：沿用现有消息请求。
- **关键响应字段**：`context_stats`。
- **数据来源**：当前 Snow Grass API。

## 8. 技术实施方案

### 8.1 架构决策

| 决策 | 选择 | 原因 | 放弃的方案 |
|------|------|------|-----------|
| 占用口径 | estimated_tokens / token_budget | 与实际上下文构建和裁剪一致 | 累计输入输出 Token |
| 实时来源 | run.started SSE | 无额外请求且数据最新 | 前端字符数估算 |
| 历史来源 | Session Memory API | 已有持久化统计 | 执行事件历史恢复 |

### 8.2 数据流

```text
run.started.context_stats / GET session memory
→ AgentPage.contextStats
→ ChatComposer.ContextUsageMeter
→ 输入框上下文刻度
```

### 8.3 改动详情

#### `snowGrassApi.js`（修改）

#### `AgentPage.jsx`（修改）
- 新增 `contextStats` 状态；新会话重置、历史会话恢复、实时事件覆盖。

#### `ChatComposer.jsx`（修改）

#### `agent.css`（修改）

### 8.4 状态管理

继续使用 React `useState`，不新增全局 Store。

### 8.5 异常处理

| 场景 | 处理方式 | 涉及文件 |
|------|---------|---------|
| Memory API 失败 | 不阻塞会话消息加载，显示暂无上下文数据 | `AgentPage.jsx` |
| token_budget 为 0 | 不计算百分比，显示 `--` | `ChatComposer.jsx` |
| 占用超过预算 | 百分比显示可超过 100%，环形进度封顶 | `ChatComposer.jsx` |

## 9. 验收标准（AC）

### AC1：实时占用
- **Given**：用户发送消息并收到 run.started。
- **When**：SSE 带有 context_stats。
- **Then**：输入框展示与事件一致的已用 Token、预算和百分比。

### AC2：历史恢复
- **Given**：会话已有 last_context_stats。
- **When**：用户重新打开该会话。
- **Then**：无需再次发送即可展示最近一次上下文占用。

### AC3：无数据状态
- **Given**：新会话尚未执行。
- **When**：显示输入框。
- **Then**：上下文刻度显示暂无数据且不出现 NaN/Infinity。
