## 执行顺序说明

- **第一批：后端数据闭环** — 模块 0 → 模块 1 → 任务 6.1 中的索引/管理用例。
- **第二批：挂载与使用控制** — 模块 2 → 模块 3 → 模块 4 → 任务 6.2/6.3。
- **第三批：知识管理 UI** — 任务 5.1 → 5.3/5.4 → 5.5 → 5.6 → 前端构建与手动交互验证。
- 同一模块内按类型/持久化 → API → 业务服务 → UI → 样式的顺序实施。
- 每批完成后运行 Snow Grass `pytest`、`ruff`、`mypy`；第二批运行 FatPet 相关测试；第三批运行 Sedum build。
